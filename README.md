## ***Phần 2: Lựa chọn***

  - 1. Cấu trúc mô hình 3 Profile chuẩn
      Profile 1: Personal (Cá nhân)
  
      Mục đích: Giải trí, học tập cá nhân, tài khoản mạng xã hội, email cá nhân, ngân hàng.
  
      Tài nguyên đi kèm: Bookmark bài viết blog công nghệ, sở thích; các extension giải trí, chặn quảng cáo, bảo mật cá nhân.
  
  - Profile 2: Work (Công việc / Dự án LMS)
  
      Mục đích: Đăng nhập tài khoản nội bộ công ty (LMS Admin/Dev, Jira, GitHub, Slack/Teams, tài liệu API nội bộ).
  
      Tài nguyên đi kèm: Lưu trữ toàn bộ Bookmark tài liệu kỹ thuật (Swagger, Figma, Doc specs, CI/CD dashboard); cài đặt các extension phục vụ phát triển (JSON Formatter, React/Vue DevTools, Postman Interceptor, Color Picker).
  
  - Profile 3: Sandbox / Test (Môi trường kiểm thử & Khách)

      Mục đích: Đăng nhập các tài khoản test (Học viên, Giảng viên, Khách vãng lai) phục vụ debug và tái hiện lỗi.

      Tài nguyên đi kèm: Bookmark trực tiếp các trang chức năng đang code/test, danh sách tài khoản test mẫu; cấu hình chặn cache khi mở DevTools để phục vụ kiểm thử nhanh.
